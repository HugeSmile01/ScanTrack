Documentation

A complete guide to creating QR codes, tracking attendance, accessing the dashboard, and exporting DepEd-compliant SF2 reports.

Launch Attendance Scanner

1. How to Create a QR Code

To generate a QR code for your students:

  1. Go to the QR Code Generator.
  2. Enter the student’s LRN, grade level, and full name.
  3. Click Generate to create the QR code.
  4. Click Download to save a printable version.

2. How to Search Attendance Records

To view attendance logs for a student:

  1. Visit the Search page.
  2. Enter the LRN or student name.
  3. Click Search to view logs.

3. System Requirements

ScanTrackSys works best on modern browsers with JavaScript enabled:

  • Google Chrome (latest)
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

4. Troubleshooting

  • Make sure all input fields are filled in before generating QR codes.
  • If a QR fails to appear, refresh the page and try again.
  • Double-check the LRN when searching for attendance.
  • Clear browser cache if the system doesn’t load properly.

5. DepEd Teacher Access

DepEd-verified teachers may sign in here using their official email to access the dashboard and SF2 Excel reports.
