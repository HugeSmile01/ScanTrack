Getting Started

  1. Generate QR Codes: Input student info (LRN, Grade, Name) to create printable codes.
  2. Track Attendance: Use the web scanner or manual form to log daily presence and remarks.
  3. Review Logs: View class-wide attendance and individual student history in the dashboard.
  4. Export SF2: Download class attendance summaries in the official DepEd SF2 Excel format.
